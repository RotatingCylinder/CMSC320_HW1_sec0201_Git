Q1: Why might we consider using Git?

Answer: There are multiple reasons to consider using Git
Git makes storing and sharing a codebase simple. 
Its version control scheme also helps to manage collaborative codebases; 
Git lets us know who coded what, resolve conflicts in the codebase, easily roll back to an earlier version, 
and experiment through forks.   

Q2: What field could data science be applied to? Give an Example.

Answer: Data science can be applied to sports scouting. I'll use soccer as an example.  
Instead of only looking at goals and assists, we can measure things like chances created, 
touches in the final third, number of line breaking passes, etc. 
Then using data science, we can analyze this data to assess the player's strengths, weaknesses, 
and overall profile. A team can use that analysis to decide which players they should recruit. 


Q3: What is the difference between Merging and Rebasing?

Answer: A rebase will repeat each commit made to a branch onto your main. A merge will create a merge commit 
which combines both branches.
